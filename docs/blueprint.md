# **App Name**: Livestock Ledger

## Core Features:

- Animal Scan: RFID scanning for animal identification, using keyboard-wedge input, NFC, or QR code.
- Manual Data Entry: Manual entry of animal data with form validation.
- Symptom Checker: Chat interface for livestock symptom triage. Use LLM tool for identifying potential conditions based on symptoms.
- Animal Profile: Display animal profile information, including events and health records.
- Event Logging: Log forms for quick data entry of milk yield, weight, vaccination, and health events.
- Alerts Center: Alerts center for displaying due vaccinations and critical health alerts.
- Data Export: CSV export for animals, events, and health records.  Date ranged CSV and Excel option.

## Style Guidelines:

- Primary color: HSL 200, 70%, 50% (RGB Hex: #33A6C8), a calming blue tone that conveys trust and health, appropriate for animal care.
- Background color: HSL 200, 20%, 95% (RGB Hex: #F0F8FA), a very light desaturated blue to maintain a clean and airy feel.
- Accent color: HSL 170, 70%, 40% (RGB Hex: #27A889), a contrasting teal/green to highlight interactive elements and status indicators.
- Body and headline font: 'Inter' sans-serif for a modern, objective, neutral look, suitable for clear data presentation.
- Use clear, outlined icons for navigation and actions to ensure ease of use. Icons to relate to the type of data displayed, such as milk, meat, health, and scans.
- Prioritize a desktop-first responsive design with airy spacing, rounded corners, and soft shadows for a modern, accessible look.
- Subtle transitions and animations to enhance user experience when logging events.
