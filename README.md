# Evex: Professional Farm OS

Evex is a robust livestock management and farm operations platform built with **Next.js 15** and **Neon PostgreSQL**. It provides a comprehensive suite of tools for tracking animal health, production, breeding, and farm inventory.

## 🚀 Key Modules

- **Livestock Management**: Detailed animal profiles with health history, production metrics, and breeding records.
- **Feed Inventory**: Track farm supplies with automated low-stock alerts and restock monitoring.
- **Health & Monitoring**: Vaccination schedules with proactive alerts and medical expense tracking.
- **Data Visualization**: Real-time production trend analysis using Recharts.
- **Multi-Language**: Full localization support for English, French, and Arabic.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Database**: Neon PostgreSQL
- **Visualization**: Recharts
- **Icons**: Lucide React
- **Date Handling**: date-fns
- **Localization**: next-intl

## 📦 Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Configure environment variables in `.env` (Neon DATABASE_URL)
4. Run the development server: `npm run dev`
